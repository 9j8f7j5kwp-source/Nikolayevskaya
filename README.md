# Кафе «Николаевская» — концепт-сайт

Статический сайт без сервера и сборки: `index.html`, картинки в `img/`, шрифты в `fonts/`.
Работает на GitHub Pages и на любом обычном хостинге.

## Как выложить на GitHub Pages

1. Создайте на GitHub новый репозиторий, например `nikolaevskaya`. На бесплатном аккаунте он должен быть публичным.
2. Нажмите **Add file → Upload files** и перетащите всё содержимое этой папки: `index.html`, `README.md`, `.nojekyll` и папки `img` и `fonts`. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/nikolaevskaya/`.

Свой домен подключается там же, в поле **Custom domain**.

## Что поменять перед публикацией

- **Права на изображения.** Рендеры интерьера, рисунки и материалы взяты из проекта POETICA (автор Адриана Варелджян, HSE Design). Перед публичной публикацией нужно письменное согласие автора или собственные фотографии.
- **Название.** «Николаевская» встречается в заголовке, шапке и подвале `index.html`. Его можно заменить поиском и заменой.
- **Цены.** Это план на 2027 год из таблицы себестоимости.

## Ограничения

- GitHub Pages подходит для витрины. Заказ и оплату через этот сайт принимать нельзя: правила GitHub запрещают использовать Pages для коммерческих транзакций, а данные заказов по 152-ФЗ нужно хранить в России.
- Перед запуском сайт лучше перенести к российскому хостинг-провайдеру из реестра Роскомнадзора. Файлы переносятся без изменений.

## Шрифты

Old Standard TT, Golos Text и IBM Plex Mono распространяются по лицензии SIL Open Font License 1.1. Тексты лицензий лежат в `fonts/`.
